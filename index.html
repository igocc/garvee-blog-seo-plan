选页与优先级故障按影响范围和严重性优先处理。健康页按持续相关曝光、缺口可修复性、证据强度和编辑／技术／验收工时排序。GSC 平均排名 10–20 是机会筛选条件之一；高曝光低 CTR 或重要页下滑也纳入评估。
同页多词、同词多页同页归并同意图词，只发一个页面任务，其余重要词设护栏。跨页用候选 query 精确筛全站，解除 Blog 路径限制补取 Blog、商品页和分类页的 Query × Page。固定集合比较合计可见点击与各页份额；合计稳定且页面满足不同需求可维持；意图重复、主页面持续错位且合计下降，再检查正文区分和相关内链。
工具负责什么SEMrush 美国 Volume/KD 补充需求和竞争估计，缺数可继续。美国 SERP 记地区、语言、设备、时间、自然位、可见深度及页型，用于判断搜索意图。Ahrefs 用同日同页型的 URL 级数据比较引用域、外链及 UR，DR 另记域级。内链用 Ahrefs 与站内抓取（Codex）按同范围核对唯一来源数及链接出现次数，抽验实际链接。

4A/B/C 什么时候可以做

常规工作采用按需优化。只有样本量、内容供给、编辑与公网验收产能均足够时，才比较「一次集中交付」与「分批交付」。A/B/C 组分别每篇每完整周实际发布 1／2／3 次，另加一个同期 0 次未改组。试验前冻结每页的内容量、类型、排期和工时上限。A 组完整内容较早上线，抓取机会也会随排期变化，因此结论适用于整套发布节奏，无法单独剥离纯次数效应。

  • 分配与窗口：按主题、流量量级、历史趋势和季节性配组，再在组内随机分配。相互分流页优先排除，必要时以整个固定页簇为分配单位。建议先测算 4 个完整周（K＝4）的可行性，用干预前等长基线（7K 日）与共同日历干预窗（7K 日）比较。候选主对比为 C 对 A，分组前锁定。干预结束后可另看 28 天持续性，记录各组交齐内容与搜索侧版本重叠，禁止将后续窗直接解释为各页已有相同 Google 暴露。
  • 执行与分母：每次公网验收通过后，按计划发布下一次，搜索侧抓取证据异步跟踪。全程保留原分配。用有完整前后观测的页或页簇计算平均点击变化，同列原分配数（N）、有效数（m）、缺失率（(N－m)/N）和缺失原因；页簇采用固定成员的点击合计。报告缺失对全组比较的敏感性，无可信界限时明确标明「全组差无法界定」，不得默认为零。
  • 启动和停止：用历史波动和最低有意义的点击差估算样本，核每周 nA＋2nB＋3nC 次发布的编辑工时与公网验收容量，分配前锁定期限、损失线和故障停机条件。护栏触发先查因或暂停。到期以点击差及不确定范围、工时成本、故障率综合判断是否扩大。低量或比较组不足时只报观察方向。具体样本数、门槛、预算和启动日期须依实际 GSC 数据与团队资源确定。
